# InternGrow-Task3-AIMusicSoundscapeGenerator_By-Noor
AI Music &amp; Soundscape Generator built with Python, TensorFlow, LSTM, Music21, and Streamlit. Generates original music and mood-based soundscapes from MIDI data. Supports multiple modes including Happy, Sad, Emotional, Relaxing, and Energetic, delivering unique AI-generated musical compositions.
