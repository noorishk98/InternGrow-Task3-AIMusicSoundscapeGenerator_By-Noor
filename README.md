# AI Music & Soundscape Generator

AI Music & Soundscape Generator built using Python, TensorFlow, LSTM, Music21, and Streamlit.

## Features
- AI-generated music compositions
- Mood-based music generation
- Happy Mode
- Sad Mode
- Emotional Mode
- Sleepy Mode
- Energetic Mode
- MIDI file generation
- Deep Learning using LSTM

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Music21
- Streamlit
- Pretty MIDI

## Project Files
- download_dataset.py
- preprocess_data.py
- train_model.py
- generate_music.py

## Run

pip install -r requirements.txt

python download_dataset.py

python preprocess_data.py

python train_model.py

python generate_music.py
